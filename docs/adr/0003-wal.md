# ADR 0003: Checksummed redo WAL

Status: accepted design, implementation pending.

Use bounded, versioned records carrying transaction IDs, sequence numbers,
checksums, page images and commit markers. Sync WAL before commit acknowledgment
or data-file writes. Replay only complete committed transactions. Full page
images initially favor torn-write repair over compact log size. Checkpoint and
truncation ordering requires explicit crash tests. Checksums alone cannot recover.
